Authentication vulnerabilites:
  Authentication: checking if the user is who they claim to able
  authorization: checking if a user is allowed to do something
  brute forcing: automating the process of sending login credentials. most times usernames are either publicly shown or predictable(eg first.lastname@company.com).
                 passwords could be somewhat less random, due to human nature. eg instead of random characters it could be Mypasswd1! and subsequent changes, only tweak 1-2 characters
  username enumaration: in register pages check for already taken usernames, or in login check for correct username but wrong password

  skipping 2fa: sometimes, when 2fa is prompted, the user is already in a loggedin state and can manually change the url to access content
